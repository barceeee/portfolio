# Runtime for the Ball-Lalo demo

Unmodified files from two npm packages by Sean Morris (Apache-2.0 OR GPL-2.0-only):

- `php-cgi-wasm@0.2.0`: PHP 8.2 CGI compiled to WebAssembly, run in a service worker
  (`PhpCgiWebBase.mjs` + its imports, `php8.2-cgi-worker.mjs`, the `.wasm` binary)
- `php-wasm-sqlite@0.2.0`: the `sqlite3` extension (`php8.2-sqlite.so`) and `libsqlite3.so`
